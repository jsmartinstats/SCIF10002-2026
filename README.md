# SCIF10002: Introduction to Coding and Data Analysis for Scientists (2026)

Course materials for SCIF10002, University of Bristol.

## Course leaders

- **Dr Francesco Turci** (course director, School of Physics): f.turci@bristol.ac.uk
- **Dr James Martin** (lecturer, School of Mathematics): james.martin@bristol.ac.uk

## Material

Each week's material is released in its own folder (`01`, `02`, ...) as the course progresses. A folder contains:

- the **lecture slides** for that week, and
- the **exercise notebooks** (Jupyter notebooks, `.ipynb`) that you work through during the lecture practical.

The notebooks are designed to be run in Noteable; the first lecture explains how to open this repository there.
